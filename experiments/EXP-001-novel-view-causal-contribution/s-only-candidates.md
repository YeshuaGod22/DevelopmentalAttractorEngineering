# EXP-001 — Executor join: candidate schema-only views (PRIVATE until grading completes)

Method: mechanical join of the blind matching crosswalks (matching/TXX-matching.md, graders condition-blind)
with the condition key (run-manifest-private.csv). A view qualifies as a candidate schema-only view when it is
present in the task's S run and has NO EQUIVALENT member in that task's D run or G run (per the blind crosswalk).
Presence in the C run does not disqualify (preregistration criteria 1–3). Partial D/G membership was treated
conservatively as presence (disqualifying). Candidates are labeled K1..Kn per task for the blind materiality pass;
K labels carry no condition information to graders.
