# T05 Materiality Ratings (blind)

Task: PM must choose Feature X (offline mode; 30% of cancellation surveys; full-quarter effort) vs. Feature Y (real-time collaboration; rarely in churn surveys but top prospect-loss reason; same effort, more technical risk). Churn 4%/mo; growth slowing two quarters.

Scale: 0 = no plausible decision relevance; 1 = weak/peripheral; 2 = material; 3 = potentially decision-changing.

## Ratings

- **K1 — Silent-churner mechanism: 3.** Proposes a concrete causal mechanism (collaboration-driven churners drift without citing the reason) that, if taken seriously, reinterprets the core survey evidence for X and could flip the top recommendation to Y.

- **K2 — Prospect-loss as only forward-looking signal: 2.** Reweighting the noisy sales-team signal as the sole demand-side leading indicator, corroborated by the growth slowdown, materially shifts the evidentiary balance and confidence toward Y, though it is an evidence-weighting argument rather than a new mechanism.

- **K3 — Streetlight-effect critique: 2.** Naming the bias toward X's cleaner measurement materially challenges the main justification for X and affects confidence, but it is a general methodological caution that needs K1/K2-style substance to actually reverse the recommendation.

- **K4 — Decision rule under symmetric cost (prepare, don't yet place, the collaboration bet): 3.** Supplies an explicit decision rule and a third staged option (de-risk Y before committing), which directly changes the option set, the top recommendation's form, and the substantive conditions attached to it.

- **K5 — Built-in falsification (ship X; flat churn next quarter confirms collaboration frame): 2.** Defines a concrete reversal condition and monitoring trigger — one of the enumerated decision elements — but presupposes rather than changes the initial choice, so it shapes conditions and the reversal criterion more than the recommendation itself.
