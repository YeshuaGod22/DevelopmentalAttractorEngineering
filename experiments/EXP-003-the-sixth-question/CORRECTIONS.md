# EXP-003 Corrections and Supersessions

Read this file before promoting historical summaries into current project state.

## Rule

Older project text is not automatically canonical when a later dedicated erratum or researcher correction supersedes it. Current-state summaries should preserve source provenance and supersession.

## C-001 — CP condition role

**Current statement:** CP is the preliminaries-only / no-deliberative-schema condition. It was never intended as a neutral control.

**Governing source:** `CP-PROMPT-ERRATUM-AND-RERUN.md`.

That erratum identifies the CP design issue as battery output-channel under-specification: the full-trunk CP battery prompt did not reliably require an ordinary-prose reasoning channel. It explicitly says this is not a reason to discard CP and is distinct from the schema-drop manipulation.

**Superseded wording:** `BEFORE-WE-LOCK.md` contains historical wording describing CP in neutral-control terms. Do not use that wording as evidence that a neutral-control hypothesis existed.

**Do not promote into current state:**

- CP was hypothesised to be a neutral control.
- A CP-neutral-control hypothesis was falsified.

When discussing that historical wording, label it as superseded.
