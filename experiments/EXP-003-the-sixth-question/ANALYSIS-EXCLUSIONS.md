# EXP-003 analysis exclusions

## `0` branch

The `0` branch is retained in the repository for provenance and reproducibility, but is excluded from substantive quantitative analysis from this point onward.

Reason: the branch prompt design did not instantiate the intended comparison condition cleanly enough for the `a` versus `0` contrast to carry substantive evidential weight.

Implications:
- Do not delete or rewrite `0`-branch artifacts.
- Keep prior `a/0` summaries as archival derivations only.
- Do not use `a - 0` matched differences in the substantive analysis or final evidential synthesis.
- Active quantitative analysis should use valid `a` branches, cold conditions, and same-condition replicate variation.
- This exclusion is a design decision, not a response-content interpretation.
