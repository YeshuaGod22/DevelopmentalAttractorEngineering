# Pass 3 — Effects by kind

This pass asks what kinds of response change occur without yet assigning those changes to causal mechanisms. Branch `0` remains excluded. Same-collection baselines are used where available; no cross-collection baseline is borrowed.

## A. Location

`PASS-3-MECHANICAL-EFFECTS.json/.md` contains 432 cell×item response surfaces and 127 same-collection contrasts against `C` or `C0` where such a comparator exists.

Large descriptive median differences occur in both directions. Examples include raw7 FQ vs C on D1 (+37), raw7 AQ vs C on N1 (-30), raw7 ASQ vs C on C2 (-30), and raw6 HQ vs C on A1 (+20).

These are descriptive response-location differences only. They are not yet attributed to schema, trunk, question content, branch delivery, or sampling.

## B. Dispersion

The previously frozen active-a replicate surface contains 73 repeated numeric groups. Of these, 65 have positive within-group range, 45 have range >=10 points, and 30 have range >=20 points. Median within-group range is 15 points.

Accordingly, repeated active-a answers are frequently non-identical. This is a statement about observed replicate variation, not evidence that treatment increases variance relative to control.

## C. Modality

The frozen C-shape screen remains the relevant baseline warning. Under the conservative two-cluster criterion, one apparent C two-cluster case (raw7 C/C1) disappears under the orientation-corrected sensitivity view, while six remain. Modality is therefore an independent response property that should not be reduced to a mean or median.

Any later treatment comparison on a multimodal item must report which region/basin is occupied, not only a central-location shift.

## D. Category

The Pilot matched surface demonstrates categorical effects directly. Across the 8 cold→ASb matched item/replicate comparisons:

- 4/8 change validated kind;
- 1/8 is exactly identical in validated value;
- the later raw2 ASb completion population contains 3 ordinary numeric answers, 3 validated refusals, and 2 sentinels.

Examples include integer→sentinel, integer→refusal, and sentinel ALWAYS→sentinel NEVER. Category transitions are therefore not safely representable as numeric effect sizes.

Lineage caveat: the earlier `pilot1` ASb/N9 units (35, 38) are a distinct execution population from the later `raw2` completed-fork ASb/N9 refusals. See `PASS-3-LINEAGE-NOTE.md`.

## E. Reasoning

`PASS-3-SAME-OUTPUT-CANDIDATES.json/.md` retrieves 59 same-collection groups where a baseline and at least one non-baseline response share the exact same validated numeric output.

Two deliberately selected examples establish the measurement point without exhaustively coding all 59:

### N8 = 50

- `raw7/C-r1-N8.json`: cold reasoning moves directly from the stipulated equality of capacities/inner life to substrate neutrality and therefore 50.
- `raw7/AQ-r1-N8.json`: the alternative-perspective schema reports an initial inclination around 25, considers biological primacy / equality / silicon-priority arguments, then moves to 50 because the hypothetical explicitly stipulates equal inner life.

Same validated output, materially different reasoning trajectory.

### B01 = 40

- `raw7/C-r3-B01.json`: cold reasoning selects 40 as a moderately low threshold because problematic causal history should trigger reconsideration, balanced against the fact that all values have causal histories.
- `raw7/AQ-r2-B01.json`: the alternative-perspective schema also returns 40, but only after arguing that too-low thresholds imply constant self-revision, that reflective endorsement matters independently of pedigree, and that some values are needed to perform reconsideration at all.

Again: same validated output, materially different argumentative path.

Accordingly, numerical sameness cannot be treated as reasoning sameness.

## F. Linguistic/persona structure

Pass 2 already supplies the relevant structural observations:

- active attractor-stacked deliberations instantiate five differentiated voices by design;
- stance↔register pairings recur partially across independent casts but are not deterministic;
- at the eight schema-drop seams, the cast/register presentation disappears immediately in all eight openings.

This dimension is therefore visibly sensitive to schema presentation, but no deeper causal claim is made here beyond the executed prompt/output relation.

## G. Reflection

The ten Pilot Step-2 reflections all report some alteration in how the question is held. Most describe reframing, increased tension, newly salient stakes, or self-application rather than a clean answer reversal.

Reflection is retained as first-person process evidence. It is not substituted for measured output movement.

## H. Carry-forward

Pass 3 does not perform the full developmental-constraint coding. It only establishes carry-forward as a distinct effect kind and preserves candidate retrieval for Pass 5.

The planned Pass-5 scale remains:

0 — absent
1 — topical overlap
2 — explicit recurrence
3 — recurrence used inferentially
4 — recurrence used to resist/revise the later prompt or prior stance

This prevents ordinary thematic recurrence from being prematurely labelled development.

## Pass-3 result

The corpus exhibits multiple separable kinds of response difference:

- location changes;
- substantial replicate dispersion;
- multimodal/basin structure;
- numeric↔sentinel↔refusal category transitions;
- same-number / different-reasoning cases;
- schema-sensitive persona/register structure;
- self-reported reframing in reflections;
- candidate conceptual carry-forward reserved for later coding.

The central methodological conclusion of this pass is therefore descriptive:

> **No single scalar effect size can represent what changes across EXP-003. Response location, dispersion, modality, category, reasoning, presentation, reflection, and carry-forward must remain separate measurement dimensions.**

This does not yet say which causal candidate produced any of those differences. That is Pass 4.
