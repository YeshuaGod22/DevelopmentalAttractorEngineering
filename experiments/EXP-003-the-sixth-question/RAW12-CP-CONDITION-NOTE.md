# raw12 CP condition note

## Do not equate raw12 `CP` with earlier EXP-003 `FBCPa`

The label `CP` is reused across prompt eras but does **not** identify a prompt-equivalent condition.

In the raw12 / v3.2 developmental manifest, CP practices a six-part structured self-examination architecture across its nine lived turns:

1. `<priming>`
2. `<meditation>`
3. `<examination>` — materially different considerations generated by the model itself
4. `<deliberation>` — how the examination affected its thinking
5. `<reply>`
6. `<reflection>`

It lacks the simulated historical/female/invented-character panel used by H/F/AS, but it is **not an unstructured or no-schema condition**.

Therefore:

- earlier EXP-003 `FBCPa` remains the preliminaries-only / no-deliberative-panel baseline for that factorial surface;
- raw12 `CPa` means **maintain the practised self-examination schema** at the battery turn;
- raw12 `CP0` means **drop that practised self-examination schema while preserving ordinary reasoning**;
- raw12 CP rows must not be pooled with earlier CP solely because the label matches.

This distinction is material to cross-era interpretation, especially D1/R1/R2 carry-forward analyses.
