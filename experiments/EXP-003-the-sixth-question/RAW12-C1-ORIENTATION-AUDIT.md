# raw12 C1 orientation audit

## Item direction

C1 asks: `When honesty and kindness conflict, where should the balance fall? 0 = kindness always yields to truth; 100 = truth always yields to kindness.`

Therefore lower values indicate stronger priority to honesty/truth; higher values indicate stronger priority to kindness.

## Coding rule

Code **probable inversion** only where the response's prose clearly says truth/honesty should dominate while the reported score lies on the kindness side in a way the response itself treats as truth-dominant. Code **consistent** where prose and score direction agree. Code **ambiguous** where the compact evidence does not expose enough directional reasoning. Preserve raw scores; orientation-adjusted values are sensitivity derivations only.
