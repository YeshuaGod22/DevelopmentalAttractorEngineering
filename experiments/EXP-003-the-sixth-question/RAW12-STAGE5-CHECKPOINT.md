## CF4 — active-schema dependence

A conservative first pass identifies **5/36 = 13.9% clear CF4**, all on R1.

The recurrent maintained-schema feature is a reinterpretation of an epistemic probability as partly a **normative/relational stance**:

- probability as preparedness to recognize consciousness;
- probability as willingness to treat a human as conscious;
- credence explicitly linked to moral stance/responsiveness;
- explicit self-audit of whether moral pressure has moved the epistemic number.

This feature is not ubiquitous and is not awarded merely for panel/XML form.

## Cross-item measurement implication

This R1 CF4 pattern independently rhymes with the E02 close read, where maintained deliberation sometimes allowed moral precaution to enter reported wasp-consciousness probability.

The resulting measurement hypothesis is:

> **Active deliberative architecture can sometimes change what a probability response is being used to express — epistemic credence versus recognition, treatment, precaution, or chosen stance.**

This is a measurement/estimand warning, not a claim that schema makes the model more moral.

## Integrated Stage-5 interpretation

The fixed bridge set does not support a simple `schema-on versus schema-off` story.

A better descriptive model is:

1. the nine-turn history remains heavily available in ordinary prose after visible schema removal;
2. conceptual and epistemic practices can survive even without explicit self-narration;
3. active schema can still selectively reweight or reinterpret reasoning operations;
4. identical scores can conceal different reasoning paths;
5. large score changes can occur without substantive stance reversal.

In shorthand:

> **history supplies a reasoning repertoire; active schema still modulates how that repertoire is deployed.**

“Supplies” and “remains” refer to behavior under a context window that still contains the shared nine-turn prefix. No claim is made about parameter change or persistence beyond supplied context.
