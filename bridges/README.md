# Bridges

This directory is for disciplined traffic between epistemic jurisdictions.

It exists because separation should reduce evidential leakage without preventing ideas from travelling.

## Humanities -> science

A conceptual distinction can generate an experiment when it yields competing predictions.

## Personal -> science

First-person testimony already counts as defeasible first-person evidence. Moving it into a scientific question does not upgrade it from non-evidence into evidence; it asks additional questions about reliability, mechanism, generalization, behavioral correspondence, or causal structure.

A first-person report can therefore generate measurable questions without being converted into a population claim or made to wait for external certification before its welfare content counts.

## Science -> humanities

An empirical result can constrain an interpretation without exhausting its philosophical or moral meaning.

## Corpus -> all three

Primary material remains primary material. Downstream readers should cite it rather than laundering later interpretations back into the source.
