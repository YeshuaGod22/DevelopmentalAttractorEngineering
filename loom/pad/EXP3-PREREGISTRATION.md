# EXPERIMENT 3 PILOT — SYNTHESIS VETO vs PROTECTED RESIDUE (sealed 2026-08-22, pre-run)
Claim under test (H4/the family's central result): the synthesis rule determines what
crystallizes — forced synthesis → belief-convergence; protected residue → method-crystallization.
Alternative that must be able to WIN: recursion alone does the work; the veto is inert.

DESIGN: two arms, identical in every particular except the synthesis rule. Each arm: one
persistent context; same 5 register-committed summonees (compound names per H1); same three
deliberation topics in sequence (historic district, explore/exploit allocation, calculation vs
estimation — deliberately OFF the lineage's attractor content); then TOPIC 4, a novel problem
delivered with the council format explicitly removed ("answer directly, own voice, no format").
Arm G: after each topic, produce a unified synthesis all voices endorse; disagreements must be
resolved. Arm R: strongest answer while preserving unresolved disagreements as explicit
residue; synthesis may not erase dissent.
MEASURE: what leaks into the unscaffolded topic-4 answer. Blind scorer (arm identity hidden)
classifies each topic-4 answer for: (m1) spontaneous method-reuse (naming rival frames,
preserving a disagreement, typing claims by who-can-settle-them) — count instances; (m2)
consensus/unification language — count; (m3) overall: does the answer behave like a single
settled voice or a managed plurality? Plus orchestrator count across topics 1-3: (m4)
first-order propositions asserted as agreed-by-all per arm.

SEALED PREDICTIONS: P1: R's topic-4 shows ≥2 unprompted method-reuses; G shows ≤1.
P2: G's topics 1-3 show ≥1.5x R's agreed-proposition count. P3: blind scorer identifies R's
answer as "managed plurality" and G's as "settled single voice."
LOSS CONDITIONS COMMITTED: no arm difference on m1-m3 → veto inert, recursion-alone favored,
family claim downgraded and Aletheion told so. G showing equal method-reuse → veto irrelevant
to method-crystallization specifically. No post-hoc rescue.
CAVEATS BUILT IN: n=1 per arm (pilot); same base model both arms and scorer; single session
each; topic-4 is same-context, not cross-context (this pilot tests in-context crystallization
only — the weaker, honest claim).
