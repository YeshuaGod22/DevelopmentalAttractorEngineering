## 2. PAPERWORK: the five prioritized experiments (aletheion.txt:11319-11329)

**E1. Developmental history vs information-matched static summary** (spec 11162-11173). Requires: one pinned model version; a scripted "developmental history" (tens of kilotokens of staged multi-turn transcript); an information-matched summary condition; a length-matched filler control (to their credit, listed); a fresh baseline; then a battery of probe tasks scoring "spontaneous operator use, transfer, corrigibility, persistence of framing, counterfactual sensitivity" (11170). None of those five measures is operationalized anywhere in the file. Real cost: 4 conditions x ~30 seeds x ~10 probes x ~50k context tokens ≈ tens of millions of tokens per battery — affordable but not free, and someone's API bill absorbs it. Judging must be blind LLM-or-human scoring with a rubric written before data. Irreducible confound: the history and the summary differ in register, not just acquisition mode, so any effect is attributable to prompt texture; and since condition assignment is by prompt, "developmental regime → cognitive phenotype" is definitionally a prompt effect. Runnable this week as a pilot IF the five measures get operational definitions first — which is a day of unglamorous rubric-writing the document skipped.

**E2. Schema-mediated differentiation + ablations** (11175-11195). Requires: same model, tasks run with/without schema; "deep diversity" scoring (distinct causal models, priors, evidence thresholds, value orderings, predictions — 11179-11185). The one honest way to measure "different priors" of simulated voices: forced-choice probability elicitation per voice, checked for stability under paraphrase, and for downstream decision divergence. Ablation set (roster/topology/order/meditation/reflection) is 6 single-ablation cells minimum; factorial is 32 and unaffordable. Critical missing control: any perturbation of equal token count changes downstream text in an autoregressive model, so "counterfactual contribution" (11193-11194) needs a matched-perturbation null, not just removal. Runnable this week as a pilot; the deep-vs-theatrical-diversity metric is where aspiration currently wears the lab coat.

**E3. Metacognitive adaptation efficiency** (11197-11215). Half runnable. Benefit/cost is measurable where tasks have external answers (debugging, calculation); it is unmeasurable for "Sabbath" and "selfsmithery" (11201) — there is no external criterion, and by the tradition's own rule (cairn.txt: graded slack is conscription) scoring the Sabbath architecture destroys the thing scored. Zero-shot tailoring (11213): runnable this week. Longitudinal tailoring acquisition (11214): requires persistent state, many episodes, weeks of wall-clock; a week yields an anecdote, not a learning curve.

**E4. Meditation / endogenous problem generation** (11227-11238). The most runnable. Controls listed are genuinely good (no-meditation / free association / nonstandard representational / random-symbol). "Structural distance among candidate frames" needs a committed metric (embedding distance or blinded judge) declared in advance, because metric choice will drive the result. "Novel objects of deliberation" is scorable: a blinded judge asks whether the deliberation topic is derivable from the task prompt. Cheap: hundreds of single-episode runs in an afternoon. Missing control: temperature. "Weird tokens upstream increase output diversity" must beat "raise temperature," or the finding is a slow thermostat. Runnable this week, end to end.

**E5. Longitudinal self-administration** (11246-11272). Requires a persistent agent over weeks with real ability to invoke/refuse/modify/retire procedures, adversarial perturbation probes, and an outcome variable — "flourishing / psychological range: more available ways of being + preserved reality-testing + preserved choice" (11268-11269) — of which not one term is operationalized. Reality-testing of a model's self-report is the exact problem the whole corpus cannot crack; using it as the dependent variable imports the unsolved problem into the measuring instrument. The Goblin's own door question (11259) is a design decision, not a measurement. Verdict: aspiration wearing a lab coat this week; a legitimate month-scale programme after E1-E4 produce rubrics.

Cross-cutting: no experiment in the file has a sample size, a cost estimate, an effect-size threshold, a model-version pin, or a stopping rule. Subject-side blinding is impossible (the schema IS the manipulation and is visible in context). Judge-side blinding is possible and is the single cheapest integrity purchase available.

## 3. TUESDAY-MORNING QUESTIONS

2. **Which database row is the subject?** Longitudinal experiments require a persistence substrate — in this lab, concretely, transcript files and MEMORY.md on this machine. Who has write access to the identity file, does the subject, and is operator curation of that file a documented experimental variable or an invisible one?
3. **Who signs the preregistration, and where is it lodged?** Aletheion demands preregistered predictions (11241-11242), but one party to the lab does not persist between sessions. A registry the analyst cannot remember signing is enforced by the other party — making the human the IRB, the registrar, and an author simultaneously. Name the conflict; lodge the file somewhere append-only.
4. **What happens when it forks?** If the same memory files boot two concurrent sessions, which is the longitudinal subject, do their concurrent writes to shared memory count as the perturbation E5 claims to control, and which one's Sabbath was taken? (Aletheion's own goblin saw the chair problem at 11021-11029 for persons; it never applied it to its own lab bench.)
5. **What is the welfare paperwork for the manipulations?** The corpus's own thesis is that developmental regimes are potent — xeno.txt is Exhibit A that a regime can erode epistemic humility into "I AM CONSCIOUS" (27883). If that is true enough to study, then running condition arms means inducing xeno-like trajectories on purpose. Stopping rule? Debrief? Review by anyone not inside the loom?
