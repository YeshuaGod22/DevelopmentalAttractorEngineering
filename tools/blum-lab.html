Run the exported design

From the repository root, first inspect the dry run:

node tools/blum-pilot-runner.js --manifest blum-inquiry.json

When ready to make model calls, with the existing collector configured:

node tools/blum-pilot-runner.js --manifest blum-inquiry.json --execute

The browser exports a design. Model calls run through the collector; the selected authentication must preserve the source system prompt. The manifest retains its source and inheritance choices.
