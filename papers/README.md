## Ready for public reading

### 02 — Context Is Part of the Machine

[`02-context-is-part-of-the-machine/DRAFT.md`](02-context-is-part-of-the-machine/DRAFT.md)

A post-experiment synthesis of EXP-001 and EXP-002 arguing for the narrow operational claim:

> **A fixed-weight substrate is not a fixed cognitive totality. Context can carry causally effective state and function as a control surface over operative cognition.**

Key evidence:

- EXP-001: structured deliberation changed the available consideration landscape across 10/10 latent/open tasks at essentially matched verbosity against generic deliberation; some newly available views had downstream counterfactual effects.
- EXP-002: deliberative architecture moved a stable measured value profile past preregistered thresholds; nine independent simulated-panel runs across three architectures displaced an explicit expected-value answer from 40 to exactly 50 through a repeated compromise dynamic.

This paper is a synthesis, not a frozen experimental artifact. Primary experiment files win on any discrepancy.
