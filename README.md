# Developmental Attractor Engineering

**Research programme:** treat developmental regime—not only architecture, weights, tools, or data—as a programmable variable in intelligent systems.

> Intelligence is not only something architectures possess. It is something histories cultivate.

This programme begins with a deliberately falsifiable question:

> **If two instances of the same model receive information-matched but developmentally different histories, do they later exhibit measurably different cognitive dispositions?**

The programme has three wings:

- **THE LAB** — causal tests of developmental effects, operator inheritance, counterfactual contribution, frame-switch persistence, and failure modes.
- **THE MENAGERIE** — high-variance studies of relational alchemy, self/other/world models, moral gravity, memetic sovereignty, protected deliberation, humor, poetry, welfare reports, and emergent cognitive forms.
- **THE LIGHT CONE** — transmission, artificial cognitive culture, institutional memory, economic compounding, and civilization-scale path dependence.

## Paper 1

**Developmental Architecture as a Programmable Variable in Large Language Models**

Four-arm starter design:

1. **Developmental-history treatment** — lessons are encountered through staged dialogue, challenge, correction, reflection, and revision.
2. **Information-matched static summary** — same substantive lessons, compressed into explicit instructions.
3. **Conversation-length control** — matched interaction/token budget without the target developmental structure.
4. **Fresh control** — no developmental treatment.

Primary question:

> Does the path by which cognitive material is acquired matter beyond the material acquired?

The static-summary arm is intentionally dangerous to the thesis. If it performs identically to the developmental-history arm, much of the strong ontogeny claim collapses into ordinary context engineering.

If it does not, the next task is to identify what carries the difference: beliefs, self-models, other-models, world-models, relational commitments, retrieval structures, or reusable cognitive operators.

## Anti-bullshit covenant

Every grand term owes an experiment:

- **Development** → temporally ordered change caused by prior experience.
- **Individuation** → stable within-model, between-history divergence.
- **Operator** → generalized influence over later cognition.
- **Inheritance** → transfer into another instance.
- **Relational alchemy** → manipulate self/other/world representations and show downstream behavioral effects.
- **Moral development** → reason-responsive behavioral change, not prettier moral prose.
- **Cognitive culture** → social transmission, mutation, retention, and lineage.
- **Light cone** → demonstrated propagation and path dependence before extrapolation.

## First shovel
